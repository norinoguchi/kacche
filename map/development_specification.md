Japan Discovery Maps & Calendar - AI開発指示マスター仕様書

1. プロジェクト基本方針 & デグレ防止ルール既存機能の保持: 
# 新機能の追加・修正を行う際、既存のボタン、画面、関数、ルーティング、多言語切替、自動翻訳、Nominatim連携、JSON書出・読込、テーマカラー適用、カレンダー機能（イベントモード時）などのコードを勝手に削ぎ落としたり削除しないこと。
# データ構造の型揺れ対策: スポットの多言語データ（spotContentI18n）等にアクセスする際は、数値・文字列のどちらのIDキーであっても確実にヒットするようにフォールバック処理を維持すること。   
# ファイル構成の維持: クライアントサイド完結の静的構成を崩さないこと。   
# 制約事項: 既存のボタン、モーダル、多言語切替、マップ連携、Nominatim連携、JSON書出フローなどの既存機能は、削除・改悪しないこと。   

2. システム全体アーキテクチャファイル構成: クライアントサイド完結の静的ファイル構成。   

Plaintext/
├── index.html            # ポータルページ（各マップへのランディング＆多言語切替）

└── data/
    └── {mapId}_data.json # 各マップのスポットデータ＆多言語コンテンツ (`spotContentI18n`)

3. 主要コンポーネント・機能仕様

① ポータル (index.html)
# 全マップのカード一覧表示。7言語（ja, en, zh-TW, zh-CN, ko, th, id）のリアルタイム言語切替。
# 各カードから　viewer を開くときは、現在の指定言語を引き継ぐこと。
# 各マップカードへの背景画像クロスフェード・スライドショー。

② マップビューア (viewer.html)
# ?map={mapId}&lang={lang} クエリパラメータでの起動。
# 非同期読み込みと動的適用（テーマ、アイコン、hasCalendar）。
# アイコン表示の完全連動: マップピン、リストカード、詳細モーダルのすべてにおいて、マップの種類に応じた適切なアイコンを表示（イベントモード時は春夏アイコン、スポットモード時は設定したカテゴリーアイコン）。   
# イベントマップ (event) モード: 季節（春夏秋冬）アイコンを表示。カレンダー/マップ/リストの3モード切り替え。季節フィルター。
##    開催日（イベント開始日）を参照して、春（3-5月）、夏（6-8月）、秋（9-11月）、冬（12-2月）でフィルタリング。
# スポットマップ (spot) モード: 設定されたカスタムカテゴリーを表示。カレンダービューを非表示（マップ/リスト切り替え）。
## フィルタータブのシンプル化: スポットマップのカテゴリーフィルタータブは UI 上で簡潔に「アイコン + カテゴリー名」のみを表示（説明は省略）。
# マップ上で、アイコンにマウスを置くと、そのスポットのタイトルが多言語表示される機能

③ 管理コンソール (admin.html)
# 既存マップの選択、マップ設定編集、新規マップ作成。
# スポットの追加・編集・削除、Nominatim API連携。
# 多言語翻訳機能 (Google翻訳API利用) & タブ切り替えの手動修正。
# 写真画像・フォルダパス・ライセンスの管理。
# JSONファイルの自動ダウンロードフロー。
# マップ設定編集 (editMapModal): イベント/スポットモード選択。カラーテーマ選択。
## スポットモード時は最大4カテゴリー（アイコン、名前）の設定（追加/削除可、多言語）。
# 多言語タブの改善: マップ設定・カテゴリー編集における多言語翻訳のタブから「日本語」を除外。
## 上部のマスター入力欄（日本語）が常に正となり、保存・翻訳処理と連動する。
# スポット登録 (spotModal): 定義されたカテゴリーから選択。開始日/終了日はイベントモードのみ表示。
# 新規マップ作成 (newMapModal): モード選択、カテゴリー初期設定（最大4つ、多言語）、ファイル準備フロー。
